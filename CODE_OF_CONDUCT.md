# Code of Conduct

Ghost Arcade Community follows the **Contributor Covenant v2.1**.

The full text is published at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project — through issues, pull requests,
discussions, or any other communication channel — you agree to abide
by its terms.

## Scope

This applies to all project spaces (the GitHub repo, issue tracker,
discussions, and any future Discord / mailing list / forum), as well
as to anyone representing the project in public spaces.

## Reporting

To report a concern, contact the project maintainers via GitHub's
private security advisory channel:
<https://github.com/riskcapital/ghost-arcade-community/security/advisories/new>

Reports will be reviewed promptly and confidentially.
